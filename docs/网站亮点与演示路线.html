三、机器学习、深度学习与三层可视化

录井 5 个案例均增加可训练的神经网络，并在相同训练/验证/测试划分上与传统机器学习 k-NN 比较。岩屑使用可训练卷积核的 CNN；气测、荧光、钻时和文本使用 20 → 12 的两个 ReLU 隐藏层。原有的专业基线仍可切换使用。

四、为什么这些实验值得讲

1. 分数背后有可核查的数据

岩屑分类以训练样本决定分类边界，在独立测试点上计算准确率。图像分割分别给出查准率、查全率和 F1，避免“背景像素很多”导致准确率虚高。时间预测按先后切分，测试阶段递归使用预测值；没有偷看未来观测。

2. 反例比漂亮曲线更能解释算法

气测迟到设置错误，峰形可能仍好看但层位会错；荧光曝光变化会改变原始亮度；钻时的工况扰动会制造伪界面。参数可调使这些失败原因直接出现在画面中，并反映到指标。

3. 专业知识进入模型，而非只贴标签

套管几何为带噪间隙到偏心率的回归提供标签；管柱力学为含温升×约束交互项的代理模型提供样本；测井修复用辅助曲线学习缺失段关系。它们同时保留解析或插值基线，显示数据驱动方法解决了哪一步、还没有解决哪一步。

4. 优化说明收益必须受到约束

在钻速、注水、压裂、配方及炼化实验中，二次代理模型只负责近似响应；网格搜索再检查可行性和资源惩罚。收紧上限会减少可行点，推荐值随之变化。“最优”仅针对当前教学模型、目标与网格，不被说成现场全局最优。

五、4 分 40 秒演示路线

0:00–0:35 · 交代任务与覆盖
打开首页和实验地图。说明学号 17 对应录井 5 个，扩展覆盖 13 环节、61 场景。展示每个案例均有三个标签页和独立案例包。

0:35–1:20 · 专业背景与分类
进入岩屑识别，简述岩屑返回地面的过程。切换到演示，点击开始训练并比较，展示训练与验证损失、可训练卷积核和特征图。说明按最低验证损失选轮数，再比较 CNN 与 k-NN 的同一测试集混淆矩阵；展示一个误判样本。

1:20–2:05 · 专业校正的价值
进入气测异常解释，选择“原有专业基线实验”，将迟到校正从 8 改为 0，观察区间错位和 F1 变化。说明数据对齐是方法有效的前提，异常也不自动等于工业油气层。

2:05–2:50 · 优化与约束
进入钻速参数优化，保存当前结果作对照，收紧功率代理上限，再采用网格最优点。比较可行点、响应和旧结果，解释收益与约束的关系。

2:50–3:35 · 学习模型与基线
进入测井数据修复，分别选择辅助曲线岭回归与线性插值，比较隐藏区 RMSE。说明辅助观测提供信息、遮挡真值仅用于验证。

3:35–4:15 · 扩展与复现
展示一个知识匹配关系图或原图/分割/真值三联图。导出一份实验记录，说明种子和参数可复现；演示单个案例包的下载位置。

4:15–4:40 · 收束
强调纯前端、三部分内容、可解释算法和兼容原始导入。说明全部为教学构造，录井专题已实现小型 CNN / 双隐藏层 MLP 的真实训练与推理，但合成数据指标不代表现场工程精度。

六、交付与使用

案例 ZIP 位于网站目录的“案例包”文件夹，一例一包，按“大类别-小类别”命名。所有演示可直接打开各包内的 demo/index.html；网站首页也可直接打开 index.html。

导入时先解压，选择整个案例文件夹或全部文件，保留目录结构。如果同一案例 ID 已存在，可以在导入表单使用新 ID。导入记录及学习进度只保存在当前浏览器，不会自动同步到另一设备。

这份文件是网站亮点说明与答辩准备材料，不是已经录好的讲解视频或正式课程报告。本版本通过 GitHub Pages 发布，可使用网站链接访问。演示顺序可按教师实际时长调整，现场讲解内容须与提交版本一致。
