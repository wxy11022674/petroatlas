# PetroAtlas 石油智能化可视化实验室

纯前端课程项目，覆盖 13 个石油作业环节和 61 个教学案例。录井专题包含 5 个机器学习与深度学习交互实验。

## 使用

打开仓库的 GitHub Pages 网站，或在下载后打开 `index.html`。完整界面支持案例检索、专业背景图解、方法流程、交互实验、案例导入与独立案例包下载。

## 录井专题

- 岩屑岩性自动识别：k-NN 与可训练 CNN，支持拍摄差异和误判浏览。
- 气测异常智能解释：窗口 MLP 与迟到校正。
- 荧光图像智能判读：局部窗口 MLP、曝光校正与像素分割。
- 钻时曲线地层划分：窗口 MLP 与动态规划分层。
- 录井报告自动生成：文本意图 MLP、实体抽取与模板报告。

## 数据与运行

实验采用可复现的合成教学数据。模型训练与指标在浏览器中实际计算，教学指标不代表现场工程精度。无需后端服务；浏览器保存的学习进度不跨设备同步。

## 独立案例包

`案例包/` 包含 61 个 ZIP，一例一包，采用“大类别-小类别”命名。解压后可将案例导入原框架，或打开其中的 `demo/index.html` 独立运行。

## 部署

GitHub Pages 使用 `main` 分支根目录发布，`.nojekyll` 允许直接提供静态文件。
